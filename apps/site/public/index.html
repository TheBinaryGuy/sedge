An always-on agent that lives on your machine.

sedge is pi, with a daemon behind it that keeps working after you close the terminal.

curl -fsSL sedge.sh | sh

or npm i -g @sedge-hq/sedge

  • It's pi. The same TUI, commands, models and extensions. pi comes bundled.
  • It keeps going. A daemon with an inbox and timers that wakes for each event, then sleeps.
  • It updates itself. New versions install in the background and apply when the agent is idle.
