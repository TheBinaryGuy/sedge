`sedge dash`: the dashboard on its own, full screen, with the daemon's status on top, a tab each for agents, the inbox, the outbox, timers and memory, an agent filter, and the selected item in full; it refreshes every two seconds. `/sedge` in the TUI is the same view. The TUI's theme now shades thinking levels in sedge's green. `SEDGE_SECRET_STORE=file` keeps secrets in a file instead of the keychain. The docs have screenshots.
